# 数据工程项目汇报：生物药物资料检索知识库（RAG）

## 一、数据来源

本项目构建面向医药研发与注册场景的知识检索系统，数据来源分为两大类：

**1. 本地监管指导原则文档（本地文件渠道）**
- 收录 31 份中国 NMPA（国家药品监督管理局）药品/医疗器械指导原则，涵盖生物类似药、药物临床试验设计、生物统计学、疫苗、体外诊断试剂、药物警戒等主题；
- 另有部分 FDA 产品特定指南（PSG，英文 PDF），如达比加群酯、阿卡波糖、氯氮平等参比制剂/生物等效性指南；
- 文件格式包括 .doc / .docx / .pdf，采集渠道为监管机构官方发布文档的本地归档，经解析、切分后存入向量数据库。

**2. PubMed 期刊文献（在线检索渠道）**
- 通过 NCBI Entrez（Biopython）实时检索 PubMed 生物医学文献，支持关键词与检索策略；
- 检索结果的结构化元数据（标题、作者、期刊、年份、PMID、DOI 等）写入本地 PostgreSQL 数据库，正文经向量化后入库。

## 二、处理的具体问题（业务背景）

医药研发人员在开展临床试验、注册申报与文献调研时，面临以下痛点：

1. **资料分散、检索低效**：指导原则与最新文献分散在不同来源，人工查找费时费力，无法快速定位权威依据；
2. **跨来源知识整合难**：本地监管文件与海外文献无法在同一入口检索、比对，难以形成交叉印证；
3. **引用溯源缺失**：撰写报告、申报材料时难以快速给出规范、可追溯的文献引用。

针对上述问题，项目将 PubMed 文献检索工具与基于 Chroma 的 RAG 系统整合，实现「搜索文献 → 本地入库 → 向量索引 → 生成带引文的回答」全链路自动化。

## 三、最终结果（产出成果与价值）

**1. 交付成果**
- 建成支持本地指导原则文档与 PubMed 文献混合检索的 RAG 知识库系统（FastAPI + ChromaDB + PostgreSQL）；
- 提供 8 类 API 端点（RAG 混合查询、PubMed 搜索/详情/分页/索引/删除、知识库统计），并配套单页可视化前端；
- 回答结果自动附带温哥华格式引文，本地文件以《标题》标注、PubMed 文献以 PMID 溯源，实现可点击、可复制的证据账本。

**2. 关键指标**
- 知识库规模：31 份本地指导原则 + 20 篇 PubMed 文献，累计 506 个本地向量块（含 PubMed 后 608 块）；
- 检索效率：知识库统计接口响应 75ms，文献搜索端到端 6.4 秒；
- 代码质量：pytest 420 项测试全部通过，覆盖率 91%，ruff / mypy 交付模块 0 错误；
- 集成测试：24 项端到端用例（T01–T24）全部通过。

**3. 业务价值**
- 提升医药研发文献调研与合规检索效率，实现监管依据与最新研究的一站式获取；
- 规范引用溯源，支撑注册申报材料的快速成文；
- 采用分层架构与依赖注入，便于后续扩展更多文献数据库（如临床试验注册网）。
